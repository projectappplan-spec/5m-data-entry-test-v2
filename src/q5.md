**(b)** A classmate says:

> "I installed WSL, so now I have two completely separate operating systems, Windows and Linux, running side by side, each totally independent."

Is this accurate? Briefly explain why or why not.

**Answer:**
Partially correct. Basically WSL is installed on Windows. Hence, Windows is the host where Linux lives in. If Windows shuts down, Linux goes along.
You can install WSL to run Linux on Windows but it does not run independently on Windows.

---

**(c)** Explain the difference between a **terminal (emulator)** and a **shell**, and give one example of each.

**Answer:**
Terminal is an interface where users type commands and receive output from the system. One example is Terminal on macOS.
Shell is an interpreter that turns user input command from terminal into actions performed by Kernel. One example is Bash.
